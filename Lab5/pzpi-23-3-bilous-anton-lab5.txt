                       3 КОРОТКИЙ ОПИС ПРОЕКТУ

     LumiRum – це автономна програмно-апаратна система адаптивного
освітлення, призначена для синхронізації параметрів світлового середовища з
природними циркадними ритмами людини. Система забезпечує повністю локальну
обробку даних без залежності від зовнішніх хмарних сервісів.
     Система складається з чотирьох основних компонентів:
     Бекенд реалізовано мовою Rust із використанням асинхронного фреймворку
Axum та бібліотеки SQLx з перевіркою запитів під час компіляції. Як СУБД
використовується PostgreSQL. REST API документується автоматично засобами
бібліотеки utoipa та відображається через Scalar. Аутентифікація реалізована через
JWT-токени для людей-користувачів та через API-ключ для IoT-пристроїв. Stateless-
архітектура сервера уможливлює горизонтальне масштабування: балансувальник
Caddy розподіляє запити між репліками через Docker-внутрішній DNS. Рольова
модель охоплює ролі Admin, Owner, User та Device. Математичний модуль обчислює
4-фазну криву колірної температури (2 000 K - 6 500 K) з урахуванням геолокації та
пори року.
     IoT-прошивка написана мовою C++ з використанням фреймворку Arduino
для мікроконтролера ESP32-C3. Прошивка завантажує з сервера розрахований
розклад освітлення та кешує його у зашифрованій енергонезалежній пам’яті
(NVS), що забезпечує автономну роботу пристрою навіть при відсутності зв’язку
із сервером. PIR-датчик виявляє присутність людини; LED-стрічка WS2812B
відтворює необхідний колір та яскравість через конвертацію колірної температури
в RGB. В нічний час активується спеціальний режим з мінімальною яскравістю та
червоним спектром.
     Веб-застосунок реалізовано як SPA на базі React 18 з TypeScript та Vite.
Технологічний стек охоплює Mantine v7 (UI-компоненти), TanStack Query v5
(серверний стан з кешуванням), React Router v6, axios із перехоплювачем JWT,
Zustand (клієнтський стан авторизації), react-hook-form з zod (форми та валідація)
та Recharts (графіки). Реалізовано управління пристроями та профілями освітлення,
перегляд телеметрії з 3-осьовим графіком (яскравість, температура кольору,
навколишнє освітлення), графік циркадного розкладу (96 точок × 15 хв), панель
                                                                               5
адміністратора, а також унікальну можливість експорту та імпорту налаштувань у
форматі JSON із зіставленням за іменем. Інтерфейс підтримує дві мови – англійську
та українську.
     Мобільний додаток розроблено для Android мовою Kotlin із використанням
Jetpack Compose та Material 3 (Material You з динамічними кольорами) за
архітектурним патерном MVVM. Шар даних використовує Retrofit 2 та OkHttp
з перехоплювачем авторизації. JWT-токен зберігається між сесіями через Jetpack
DataStore. Реалізовано повний функціонал: управління пристроями та профілями
освітлення, перегляд розкладу освітлення (згруповано по діапазонах температури),
власний Canvas-графік телеметрії, фільтрацію за діапазоном дат і часу, панель
адміністратора зі станом сервера та БД. Інтерфейс локалізований англійською та
українською мовами.
